# Bangkok Metro Guide — Roadmap

## Цель
Сайт про метро и транспорт Бангкока.  
Английский + русский.  
Трафик из Google → партнёрские программы.

Не приложение в сторах. Основная аудитория — туристы. Льготные и гражданские тарифы не предполагаются без проверки правил конкретной сети.

## Что убрали
- App Store / Google Play
- Скины, звук, Classic/Modern темы, онбординг
- Интеграции с Rabbit / Samsung Wallet
- Тайский язык

## Неделя 1. Данные
- Все линии: BTS (Sukhumvit, Silom, Gold), MRT Blue, Purple, Yellow, Pink, Airport Rail Link, Red Line
- Координаты станций
- Пересадки между операторами (билеты раздельные → цена складывается)
- У каждого тарифа — источник и дата
- Приблизительные цены честно помечать

### Выполнено: базовая миграция сайта
- [x] Единая модель станции: код, EN/RU, линия, оператор, тип оператора, билетная система, необязательные координаты и статус проверки.
- [x] Существующие BTS-станции сохранены; для Blue, Purple, Yellow, Pink, ARL и обеих Red Line добавлены типизированные пустые наборы и реестр линий.
- [x] Новые сети помечены как заготовки данных и не участвуют в рабочем BTS-калькуляторе.
- [x] Каждое тарифное значение содержит источник, дату добавления, дату начала действия (если известна), статус точности и дату проверки (пока не подтверждена).
- [x] Архивные цены и старая расчётная модель обозначены как приблизительные; они не заявлены как актуальные официальные тарифы.
- [x] Отдельные билеты складываются без общего лимита; Gold Line отделена от зелёной BTS. Неизвестная цена не превращается в ноль.
- [ ] Наполнить новые сети проверенными станциями, пересадками и тарифами; проверить старые координаты BTS.
- [ ] Сверить актуальные тарифы с операторами и опубликовать проверяемые первоисточники.

## Неделя 2. Структура под Google
- ~190 страниц станций (линии, выходы, что рядом, цены до популярных точек)
- ~50 страниц «Как доехать до…» (Chatuchak, Grand Palace, ICONSIAM, аэропорты и т.д.)
- 300–500 страниц самых ходовых маршрутов
- Остальное — через калькулятор
- Языки: английский и русский

### Выполнено: страницы и языки
- [x] Серверные страницы `/stations/[code]`, `/routes/[from]-[to]`, `/guides/[slug]` и каталоги со ссылками.
- [x] Английская версия по коротким URL; русская — `/ru/...`, с русским SSR-контентом и `html lang="ru"`.
- [x] Метаданные страниц; canonical/hreflang включаются после настройки настоящего домена через `SITE_URL`.
- [x] Предварительные карточки станций, маршрутов и примеры гайдов закрыты `noindex` до редакционной проверки; неизвестные адреса возвращают 404.
- [x] Звук и переключение скинов удалены; BTS-калькулятор сохранён как инструмент, светлая/тёмная тема — необязательное удобство сайта.
- [ ] Проверить тексты, выходы и последний участок пути; снимать `noindex` только у готовых страниц.
- [ ] Настроить настоящий домен, sitemap и Search Console после отбора готовых страниц.

## Неделя 3. Деньги и запуск
- Партнёрки: Klook (экскурсии), Agoda (отели у станции), Airalo (eSIM), 12Go (трансферы)
- Главные страницы по деньгам: «из аэропорта в город»
- Домен, Vercel, Google Search Console, sitemap

## Принципы
- Только полезный контент (не плодить пустые страницы)
- Честные тарифы с источниками
- Фокус на туристах (EN + RU)
- 6–8 часов в неделю
